Klausurdashboard

Browserbasiertes Prüfungsaufsichts-Tool für Klausuren an der LMU München – läuft vollständig offline, ohne Server und ohne Internet.

Browser (HTML)

Eine einzige HTML-Datei – einfach im Browser öffnen, kein Setup nötig.

macOS-App (.dmg)

Unsigniert: Beim ersten Start ggf. in den Systemeinstellungen unter „Datenschutz & Sicherheit" auf „Dennoch öffnen" klicken.

Windows-App (Setup)

Bei der SmartScreen-Warnung auf „Weitere Informationen" → „Trotzdem ausführen" klicken.

Funktionen

Countdown-Timer

Automatischer Formatwechsel: Std/Min → Min/Sek, wird unter 15 Minuten Restzeit rot.

Beameransicht

Zweites Browserfenster mit Echtzeit-Synchronisation über BroadcastChannel / localStorage.

Pause & Fortsetzen

Timer jederzeit anhalten und nahtlos weiterlaufen lassen.

WC-Status

Frei / Besetzt, automatisch gesperrt in den letzten 15 Minuten der Klausur.

Abgabestapel

Konfigurierbare Namensgruppen für eine geordnete Abgabe.

Ankündigungen

Freie Textankündigungen, die live auf dem Beamer erscheinen.

Live-Vorschau

Die Beameransicht wird direkt im Dashboard mitverfolgt.

Screen Wake Lock

Der Bildschirm bleibt während der gesamten Prüfung aktiv und schaltet sich nicht ab.

So funktioniert's

  1. Klausurdashboard.html herunterladen und im Browser öffnen (Chrome/Edge empfohlen) – oder die macOS-/Windows-App installieren.
  2. Prüfungsname und Dauer eingeben.
  3. „Beameransicht öffnen" klicken → neues Fenster auf den Beamer/zweiten Bildschirm ziehen und dort Vollbild (F11) aktivieren.
  4. Prüfung starten.
